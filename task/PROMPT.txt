为日志过滤服务制作正则安全审查器和隔离执行器，不要求解决任意正则的复杂度判定。

请从空目录实现以下可运行工具。环境为 Windows、Python 3.12、仅CPU；不使用Docker或真实外部服务。除题面明确允许的cryptography外只用标准库。输入样例、模拟组件和测试数据由你在项目内构造，不存在另行提供的附件。

核心要求：
1. 明确支持的语法子集：字面量、字符类、连接、分支、捕获组与*+?量词；反向引用和前后查找直接标记超出分析能力。构建可解释的重叠重复风险分析，输出对应语法节点和候选输入。匹配语义为fullmatch且只比较接受与否；字符类限显式字符与范围，Unicode按码点处理，不要求捕获组结果一致。
2. 候选输入在独立子进程执行标准库re，施加可配置墙钟超时与长度上限；超时后终止并回收子进程，不能让检测器本身被拖死。只把实测增长证据作为风险佐证，不声称数学证明。
3. 对可支持子集再实现不回溯的NFA匹配器，给出安全替代模式或迁移结果；语义一致性要用有界穷举字符串验证，无法保持一致时只给人工建议。

必须覆盖的验收场景：嵌套重复、互斥分支、空串量词、Unicode字符类和恶意超时样例；报告误报边界及子进程无残留的检查。

交付源代码、README、样例及自动化测试。提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v 两个入口；cases.json可引用项目内源文件或二进制样例。输入输出schema、错误码及未写明的非安全性细节自行设计并完整说明，不能放宽上述要求。测试必须断言具体结果、状态或证据，不能只打印成功；固定种子可重放。所有操作局限在项目测试目录和本机模拟服务。
